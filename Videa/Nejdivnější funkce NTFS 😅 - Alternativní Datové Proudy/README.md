## Nejdivnější funkce NTFS 😅 - Alternativní Datové Proudy

**[Video na YouTube](https://youtu.be/8FvfRiigBr0 "https://youtu.be/8FvfRiigBr0")**

**"Alternate Data Stream.cs"** slouží k překopírování celého souboru do libovolného umístění, které klidně může být alternativním datovým proudem jiného souboru. Kopírování se provádí po kusech o velikosti 64 kB, aby bylo takto možné překopírovat libovolně velký soubor

V souboru **"Hash z textu GUI.zip"** pod heslem ***grizlik*** naleznete program **"Hash z textu GUI.exe"**, který se chová jako grafické uživatelské rozhraní programu **"HashZTextu.exe"** z videa *[Proč ani silné heslo nemusí být bezpečné](https://github.com/Grizlikk/GrizlikYT/tree/noice/Videa/Pro%C4%8D%20ani%20siln%C3%A9%20heslo%20nemus%C3%AD%20b%C3%BDt%20bezpe%C4%8Dn%C3%A9)*, který slouží pro generování hashe ze zadaného textu podle zadaného algoritmu. Program **"Hash z textu GUI.exe"** se chová ***pouze*** jako uživatelské rozhraní, takže ***stále vyžaduje***, aby konzolový program **"HashZTextu.exe"** byl ve stejné složce a měl přesně tento konkrétní název, protože ho grafické uživatelské rozhraní používá pro samotné generování hashů<br>
Ve složce **"zdroj"** dále naleznete zdrojové soubory projektu ve Visual Studiu od programu **"Hash z textu GUI.exe"**

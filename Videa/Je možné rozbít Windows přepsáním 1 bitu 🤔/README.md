## Je možné rozbít Windows přepsáním 1 bitu? 🤔

**[Video na YouTube](https://youtu.be/f1BrMC5LtGk "https://youtu.be/f1BrMC5LtGk")**

**"Aplikace.c"** po spuštění pouze vypíše hlášku, že byla úspěšně spuštěna aplikace. Jako každá jiná ***.exe*** aplikace, bude (po kompilaci) začínat bajty ***4D 5A***. Pokud tyto bajty jakkoliv pozměníte, celá aplikace bude považována za neplatnou.

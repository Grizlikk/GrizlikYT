Program **"Přejmenování fotek.exe"**, který naleznete v souboru **"Přejmenování fotek.zip"** pod hlesem ***grizlik*** přejmenuje vybrané fotky na formát ***\[ROK\]\[MĚSÍC\]\[DEN\]_\[HODINA\]\[MINUTA\]\[SEKUNDA\]***. Program je zkompilovaný pro Windows a pro spuštění potřebujete *[.NET](https://dotnet.microsoft.com/en-us/download "Stažení .NET ze stránek Microsoftu \(Stačí vám .NET Runtime v \"All .NET downloads\"\)")*!<br>
Jedná se o aktualizovanou verzi [programu z minulého roku](https://github.com/Grizlikk/GrizlikYT/tree/noice/Videa/V%C3%A1no%C4%8Dn%C3%AD%20speci%C3%A1l%202023%20%F0%9F%98%80/P%C5%99ejmenov%C3%A1n%C3%AD%20fotek), která navíc podporuje ***získání datumu pořízení fotky z jejích metadat*** a ***přidání čísla za nový název souboru, pokud soubor s aktuálním názvem již existuje***

Ve složce **"zdroj"** dále naleznete zdrojový kód tohoto programu jako projekt ve *Visual Studiu*
